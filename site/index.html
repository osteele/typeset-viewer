One window for every document you read

Typeset Preview renders sources with local tools and shows the result with native PDF display.

Typst, Markdown, LaTeX & PDF

Typst renders with the bundled typst; Markdown with Pandoc; LaTeX with latexmk. PDFs open directly.

Live refresh

Edit the source in your own editor and the preview re-renders on save, keeping your place on the page.

Navigable sidebar

Move through long documents with page thumbnails, a table of contents, a figures-and-tables index, and a citation list.

Document review

Run focused checks — readability, citation coverage, proofreading, prose tightening — as reviewable suggestions.

Reading list

Collect papers to return to, add them by arXiv ID or URL, and open, search, or export the list.

Presentation mode

Turn any rendered document into slides with page-fit navigation and an optional iPhone remote.

Getting started

Typst is bundled; the other renderers use tools you may already have.

1 · Download & openDrag the app to Applications. It's notarized, so it opens without security warnings.
2 · Open a fileOpen a .typ, .md, .tex, or .pdf — from Finder, drag-and-drop, or File > Open.
3 · Add renderers (optional)Markdown needs pandoc; LaTeX needs latexmk. The app tells you if one is missing.
4 · Stay currentThe app checks for updates on its own and installs them in place.
